2. 鉴权与加密

POST phone-captchas/<ctcode>-<phone>
→
POST api/v1/tokens
→
token + user_id + encrypt
→
cookieSet(randomSplit(encrypt)) = NCG-eid
→
getOffset2(cookieGet(NCG-eid)) % 256 = OFFSET
→
Bearer + offsetEn
密码登录走另一条：GET api/v1/user-pwd-info 取本轮 user_pwd_login_salt / pwd_encrypt_key / login_iv / login_random_text，SHA256(salt+pwd) 拼 login_random_text 后 3DES-CBC-Pkcs7 加密，Base64 放 pwd 提交到 POST api/v1/user-pwd-tokens。salt/IV 每次请求都变，两步必须连着发。 
randomSplit = e => e.split(",").map(x => x.split(":")[1]).join("d")
cookieSet   = e => e.split("").map(c => c.charCodeAt() + "-" + rand2()).join("-")
cookieGet   = e => String.fromCharCode(...e.split("-").filter((_, i) => i % 2 === 0))
getOffset2  = e => getOffset(...e.split("d").map(Number).slice(1))
getOffset   = (a, b, c) => (a | b) % 256 + c
offsetEn    = (off, txt) => base64(utf8(txt).map(b => (b + off) % 256))
offsetOut   = (off, b64) => utf8(base64decode(b64).map(b => (b - off + 256) % 256))
加密只对 api/v2/ 生效：请求体加密 + 响应体解密 + 必须带 Bearer。 api/v1/ 全部明文且匿名可读 —— 这是无账号逆向的主入口。

9. 边界说明

匿名可读：首页 17 个接口、游戏列表/详情、FAQ（90 KB）、社区话题、SEO、版本配置。
必须登录：POST api/v2/tickets（启动游戏）、users/@me 系列（我的）、 common_setting（悬浮球/画质持久化）、media-servers、key_mappings。
未登录访问 v2 统一返回 HTTP 401 + {"errcode":1006,"errmsgcn":"登录信息失效，请重新登录"}。

补全登录态后再走 POST api/v2/tickets 即可拿到 gateway_url， 用 sdk/cgapi.py 的 PlaySession 连 WS、auth、收 SDP、发输入 —— 整条链路可复现。
